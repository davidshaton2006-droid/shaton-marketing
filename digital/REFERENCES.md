## Каталог паттернов и критерии
R01 — коммерческая навигация: услуга → задача → доказательство → CTA (Комаров, Webster). Проверить ссылки/клавиатуру.
R02 — уникальная предметная графика на светлом фоне (гипотеза на базе Realweb): отдельные файлы, одинаковая художественная система, без повторов; проверить края.
R03 — case-first редакционная сетка (Insa im, Webster): крупные изображения, реальные проекты, теги, статусы, ссылка в кейс; без вымышленных цифр.
R04 — мультимедиа (Диалог-Медиа, АЭРО): постер, запуск по выбору пользователя, без автозвука, pause вне экрана.
R05 — discovery (АЭРО): ветвящийся подбор, независимые главы, текстовый режим, доступность.
R06 — меню услуг/продуктов (Webster, АЭРО): явные названия, превью, mobile и клавиатура.
R07 — motion-кандидаты, а НЕ подтверждённое наблюдение: scroll parallax, image mask, spring, sticky storytelling, FLIP, page transition, spotlight; измерять и выбирать на этапах 14–15.
## Недостающий browser pass
Для каждого сайта: desktop 1440/mobile 390; кадр первого экрана, скролл, hover, меню, переход в кейс, back, focus, видео и reduced motion. Записать URL секции, действия, видимые состояния, длительность по записи, mobile fallback, скриншот/видео. Отдельно Savia. 02.08–19 и 02.21–22 не считать полностью завершёнными до этого. Не копировать чужие изображения, код, логотипы и тексты без разрешения.
