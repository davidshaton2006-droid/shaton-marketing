## 09 — material rules
Main light: broad upper-left softbox, secondary cool reflection on opposite edge; matte brushed metal has directional grain, polished edge sharp highlights, glass refraction restricted to real render, not text backgrounds. Background neutral porcelain/silver; spectrum limited to small glass reflections. Dark matte comparison is used for alpha inspection, not as site theme. Use independent file for every decorative object; do not crop/duplicate A across unrelated sections.
## Asset preparation
prepare-art.py reads only 5 existing originals and writes derivative outputs (desktop 1440, mobile 820; transparent edge padding; conservative fringe clean). Original bytes unchanged. Output manifest records SHA256, dimensions, alpha loss and edge alpha; preview composite on porcelain and graphite. Processing runs in read-only CI, never pushes itself. Import derivative bytes by verified hashes only after success and review. No claims of fixed art before inspecting output. A source, B/C/D/E alternatives preserved.
