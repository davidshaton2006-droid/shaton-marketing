# DESIGN-SYSTEM — черновой baseline, НЕ утверждённый редизайн
Этапы 04–08 предстоят. Текущая концепция Daylight Titanium; три CSS слоя style/studio/daylight с накопленным каскадом. Согласованное направление: светлый Apple Titanium + Prismatic Liquid Glass + редакционная композиция. Кандидаты токенов: #F8F9FC, #EEF1F6, #DCE3EE, #20283B, #58647A, #697FC0, #B5AAD9, #C2DCD9. Не применять все акценты одновременно. Проверить контраст до утверждения. Голос: конкретика, русская типографика, без вымышленных обещаний. Сетка 12/8/4 как гипотеза, индивидуальные композиции. Референсы и критерии в REFERENCES. После этапов 04–08 заполнить токены, состояния, responsive, визуальные примеры, правила компонентов.
