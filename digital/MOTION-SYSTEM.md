# MOTION-SYSTEM — baseline, НЕ утверждённая система
Текущие app.js/studio.js/daylight.js: pointer parallax, tilt, magnetic translate, spotlight, входы IntersectionObserver, переключатели, scene filters, demo/FAQ animation, native WAAPI fallback. CSS keyframes prism-drift, glass-float, portal-drift, cube-drift, network-float. Дубли обработчиков и эффектов — кандидат на консолидацию. Continuous network-float вероятно мешает Playwright (QA-REPORT). Этапы 14–15: токены duration/easing/spring; единое владение transform, без конфликтующих анимаций; reduced motion, offscreen pause, keyboard/touch, no scroll hijack, без скрытия текста. Входы/микроэффекты проверять отдельно, без выдуманной точности относительно референсов. Список кандидатов — ROADMAP 15.
## Исправление baseline
network-float по умолчанию paused; IntersectionObserver включает только видимую архитектурную иллюстрацию, visibilitychange и изменение reduced motion останавливают её. Нативный fallback без IntersectionObserver — неподвижная графика. Добавлен отдельный QA тест. Проверка ожидается в CI.
